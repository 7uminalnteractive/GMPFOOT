# GMPFoot (Brasfoot moderno)

Android nativo (Kotlin + Jetpack Compose). Build via GitHub Actions: aba **Actions → Android CI → Artifacts → GMPFoot-debug-apk**.

## Estrutura
- `domain/` modelos e motor de negociação de contratos (mercado de managers)
- `data/` `TeamDataSource` (fonte plugável para o editor de times) e dados de exemplo
- `ui/` telas Compose (tema escuro minimalista)
